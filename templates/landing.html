🗃️ SA Thread Archiver Suite

Complete toolkit for downloading and processing SomethingAwful forum threads

📋 Full Page Workflow

1. Download Thread (Full) → 2. Transform to JSON → 3. Generate HTML → 4. Ready to Share

🖼️ Image Gallery Workflow

1. Download Images Only → 2. Create Image Gallery → 3. Ready to Browse
📥
Thread Archiver
Download complete SA threads with centralized image organization. Supports both full page archiving and images-only mode.
📄
JSON Transformer
Convert downloaded HTML thread pages into structured JSON format with extracted posts, usernames, and timestamps.
🌐
Standalone HTML
Generate beautiful, browsable HTML archives from JSON data. Perfect for sharing or hosting thread archives online.
🖼️
Image Gallery
Convert images-only downloads into browsable HTML galleries with thread-style layout and 100 images per page.

Built with Flask • Docker • Python
